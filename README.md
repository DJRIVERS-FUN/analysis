# Executive Function and GPA Analysis

This repository contains Python-based statistical analyses and visualizations for the paper:

**Executive Function as a Proximal Predictor of Academic Achievement: A Multivariate Analysis of Metacognition, Psychological Distress, and GPA in Japanese Undergraduates**

## Planned Analyses

- Correlation and partial-correlation analyses
- Relative importance analysis
- Hierarchical regression
- GPA group prediction models
- Cluster/profile analysis
- Mediation analysis
- Publication-quality visualizations

## Recommended Environment

Python 3.11+

Core libraries:

```bash
pandas
numpy
scipy
statsmodels
scikit-learn
matplotlib
seaborn
pingouin
factor_analyzer
```
